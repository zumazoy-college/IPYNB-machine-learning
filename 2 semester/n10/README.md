# ML-Продукт для анализа отзывов

Полноценный ML-продукт для анализа отзывов клиентов интернет-магазина с веб-интерфейсом.

## Возможности

### 1. Классификация тональности отзывов

- Сравнение 3 моделей: LogisticRegression, RandomForest, XGBoost
- Метрики: Accuracy, Precision, Recall, F1-Score
- Предсказание тональности в реальном времени

### 2. Веб-интерфейс (Flask)

- Форма для добавления отзывов
- Мгновенное предсказание тональности
- Персонализированные рекомендации
- Статистика по товарам
- Визуализация данных

### 3. Персонализированные рекомендации

- Collaborative filtering на основе истории оценок
- Уникальный ID пользователя (cookies)
- Поиск похожих пользователей

### 4. Визуализация и аналитика

- Распределение оценок
- Динамика отзывов по дням
- Облако слов
- Сравнение моделей
- Статистика по товарам

### 5. Единая база данных SQLite

- Все компоненты работают с одной базой данных
- Данные сохраняются между запусками

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### Шаг 1: Генерация данных (ОБЯЗАТЕЛЬНО!)

Сначала нужно создать базу данных с начальными отзывами:

```bash
python generate_data.py --clear
```

Это создаст 200 отзывов в базе данных SQLite.

### Шаг 2: Запуск анализа данных (main.py)

```bash
python main.py
```

**Результат:**

- Консольный вывод с метриками всех моделей
- Файл `ml_analysis_report.png` с визуализацией

### Шаг 3: Запуск веб-приложения (app.py)

```bash
python app.py
```

**Откройте браузер:** <http://127.0.0.1:5000>
